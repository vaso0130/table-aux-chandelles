## 功能

- **真實洗牌與切牌**:GSR 鴿尾式交錯洗牌(`crypto` 隨機)、**三疊切牌**(點一疊即為新牌頂)、「一鍵完成儀式」(洗七次+隨機一切);步驟指示器(洗→切→抽)、工具列常駐視野;易經擲卦盤面為擲錢起卦。
- **抽牌雙模式**:預設**命運牌堆**單鍵抽頂(抽前顯示「下一張落〔位置〕」),可切換**攤牌親挑**扇形逐張點選(觸控目標已放大);「讓命運抽完剩下的牌」可隨時停止。
- **下載盤面圖與分享**:抽齊後一鍵匯出手繪符號版盤面 PNG(金框+圖徽+位置+落款,離線可用)、分享文字版(navigator.share/剪貼簿);產生 AI 提示詞即自動複製,附「開啟 ChatGPT/Claude」出口。
- **六牌陣・全景**:各牌組通用盤面(易經除外)——過去/現在/未來+助力/阻礙/結果,一事六面。
- **親手抽牌**:牌堆扇形展開逐張點選;九張以上盤面可「讓命運抽完剩下的牌」。
- **解讀帳冊**:逐位置牌義(依正逆位切換)、關鍵詞、雷諾曼組合語句;點牌面彈出牌義浮框。
- **AI 解讀 Prompt**:一鍵產生完整提示詞(牌組、盤面、位置意涵、正逆位、吉凶記號、對應、六爻紀錄、**組合語句**、各牌組體系讀法總綱、你的問題與語氣),複製貼給任何 AI。
- **牌義字典**(獨立分頁):依牌組瀏覽全部牌,含正逆位牌義、對應、雷諾曼組合語法與大盤宮位、八種常見位置的讀法示範。
- **占卜歷史**:自動存入 `localStorage`(上限 50 筆,含牌組/正逆位/起卦紀錄),可重看、刪除、清空。
- **專屬卡背**:九副牌各一款,切換牌組自動更換。

## 牌面

西方館依十九世紀鍍金石版畫式樣重繪(象牙緞紋底、洛可可金框、頂部徽章);東方館為朱紅灑金・工筆重彩式樣(雲紋回紋金框、篆印式徽章)。缺圖時網頁自動退回符號版牌面。

開發測試:`index.html?rwdtest=盤面id`(如 `nine`、`sib-fifteen`、`yi-cast`)自動完成整個牌陣;`index.html?dicttest=牌序&deck=牌組id` 直接打開字典詳細頁;別館 `astro.html?test=盤式id`、`numbers.html?test=題目id`、`bazi.html?test=命術id`、`shi.html?test=式id`、`nanyang.html?test=術id`、`kaijuan.html?test=yiju|kieu|qs`、`mix.html?test=id1,id2,id3` 以樣本資料自動起盤(成功時網頁標題為 *-TEST-OK);各別館 `?learn=1` 直達教學分頁。
