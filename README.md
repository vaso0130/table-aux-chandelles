# 燭光牌桌 · La Table aux Chandelles

網頁版占卜殿堂:牌桌館(西方館+東方館共九套牌卡)之外,另有易經館、象棋館、占星館、八字館、式占館、南洋館、開卷館、鐘樓館、鏡廳與 MIX 三術合參。直接用瀏覽器開啟 `index.html`(燭光入口:點燭動畫與十一扇門廊)即可,無需伺服器;牌桌在 `table.html`,易經館在 `yijing.html`(兩館共用 `table.css`+`table-engine.js` 儀式引擎,以 `window.TABLE_HALL` 決定收哪些牌組)。全站牌面圖點了都能看大圖(`card-zoom.js`)。

流派差異不再只藏在註腳：西洋/卜卦占星可選整宮或等宮，八字可選晚子或午夜換日，紫微可選年界與三種閏月法，南洋曜日可選午夜或清晨換日；所選規則會寫入 AI 提示詞。完整採用規則與未開放原因見 [`AUDIT.md`](AUDIT.md)。

## 功能

- **真實洗牌與切牌**:GSR 鴿尾式交錯洗牌(`crypto` 隨機)、**三疊切牌**(點一疊即為新牌頂)、「一鍵完成儀式」(洗七次+隨機一切);步驟指示器(洗→切→抽)、工具列常駐視野;易經館的起卦盤面為揲蓍／擲錢起卦。
- **抽牌雙模式**:預設**命運牌堆**單鍵抽頂(抽前顯示「下一張落〔位置〕」),可切換**攤牌親挑**扇形逐張點選(觸控目標已放大);「讓命運抽完剩下的牌」可隨時停止。
- **解讀分享圖與分享**:全站各館「解讀分享圖」鈕(`share-image.js`)把館名、時間、所問、牌面列與整份解讀排成直式分享卡,以本機 html2canvas(`vendor/`)繪成約 2160px 寬的 PNG(自動壓在 iOS 畫布上限內),先開預覽再「分享」(手機分享面板)/「下載圖片」/長按存相簿;iPhone Safari 也做得出來(舊的 SVG foreignObject 做法在 Safari 會污染畫布)。測試鉤子 `&sharetest=1`(標題回報尺寸)/`=2`(整頁換成成品圖)。分享文字版(navigator.share/剪貼簿);產生 AI 提示詞即自動複製,附「開啟 ChatGPT/Claude」出口。
- **離線版(PWA)**:`manifest.webmanifest`+`sw.js`+`pwa.js`,可加到手機主畫面。安裝時存下十三頁與各頁引用的程式、樣式、圖示;頁面先上網拿新版、斷線用存檔,帶 `?v=` 的檔案存檔優先;牌面圖看過就存,首頁可一次存齊(清單 `offline-files.json`,新增牌面圖後跑 `make-offline-list.ps1` 重產)。測試鉤子 `?swtest=1`。
- **今日一牌/今日一卦**:首頁每天第一次點燈時從八副有圖的牌與六十四卦各隨機抽一張(存 `localStorage` 的 `dc-today`,當天固定),點牌面看大圖。測試鉤子 `?todaytest=1`。
- **六牌陣・全景**:各牌組通用盤面(易經除外)——過去/現在/未來+助力/阻礙/結果,一事六面。
- **親手抽牌**:牌堆扇形展開逐張點選;九張以上盤面可「讓命運抽完剩下的牌」。
- **解讀帳冊**:逐位置牌義(依正逆位切換)、關鍵詞、雷諾曼組合語句;點牌面彈出牌義浮框。
- **AI 解讀 Prompt**:一鍵產生完整提示詞(牌組、盤面、位置意涵、正逆位、吉凶記號、對應、六爻紀錄、**組合語句**、各牌組體系讀法總綱、你的問題與語氣),複製貼給任何 AI。
- **牌義字典**(獨立分頁):依牌組瀏覽全部牌,含正逆位牌義、對應、雷諾曼組合語法與大盤宮位、八種常見位置的讀法示範。
- **占卜歷史**:自動存入 `localStorage`(上限 50 筆,含牌組/正逆位/起卦紀錄),可重看、刪除、清空。
- **專屬卡背**:九副牌各一款,切換牌組自動更換。
